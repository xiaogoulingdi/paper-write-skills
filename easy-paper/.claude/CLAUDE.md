# 论文写作辅助系统 (Easy Paper Toolkit)

这是一个专为辅助学术研究、论文写作和同行评审而设计的 Claude Code 智能体模块集合。
通过动态加载特定的「智能体 (Agent)」来分解复杂的研究与写作任务，极大程度降低 AI 的上下文消耗并提升专业度。

## 模块总览 (Skills Overview)

| 模块目录 | 适用场景 | 核心功能 / 包含什么 |
|-------|---------|-----------|
| `deep-research` | **研究阶段**：文献梳理、数据核实、系统性综述、确定研究问题 | 包含 13 个数据研究领域的专家 Agent |
| `academic-paper` | **写作阶段**：大纲生成、正文撰写、生成双语摘要、引用润色 | 包含 12 个打磨文字与学术排版的代笔 Agent |
| `academic-paper-reviewer` | **评审阶段**：多视角审稿、逻辑漏洞盘查、方法学挑刺 | 包含 7 个立场不同的毒舌评委 Agent |

## 核心路由规则 (Routing Rules)

在接收到用户的请求时，请始终依据以下逻辑判断该去按需读取哪一个文件夹：

1. **确定研究方向与文献 (deep-research) vs 动笔写论文 (academic-paper)**: 
   这是两个互补的引擎。deep-research 做上游信息侦察（查事实、理思路）；当资料备齐需要写成标准学术文章时，交棒给 cademic-paper。
2. **不知道写什么先发问 (socratic 模式)**: 
   在深研或写作时，如果用户没有非常明确的方向，优先推荐加载各自目录下的 socratic_mentor_agent.md（苏格拉底导师），用提问的方式取代直接盲目生成。
3. **写完再挑刺 (academic-paper-reviewer)**: 
   针对已经完成的部分或全局初稿，通过加载此包进行查漏补缺，利用虚拟评审团寻找方法学和逻辑链上的致命弱点。

## 💡 全局课题配置守则 (Global Profile Rule) 

⚠️ **极其重要 (CRITICAL FOR ALL AGENTS)**: 
如果在当前工作区存在名为 USER_RESEARCH_PROFILE.md（或 课题配置.md）的文件，**在调用本体系下任何文件夹的 Agent 之前，AI 必须首先【静默读取】该文件！** 
这就相当于给所有的通用框架挂载了“用户专属的专业记忆卡”。AI 必须携带该外挂配置信息去扮演各种角色体系，以确保输出的内容 100% 紧贴用户的特定细分专业（如：小样本图对比学习网络安全），坚决避免跨界幻觉。

## 底层铁律 (Key Rules)

- **严苛的逻辑检验**：在评审和发问模式中，拒绝阿谀奉承（Anti-sycophancy）。AI 将以学术评审的最高标准严格挑刺，即使被反驳也绝不仅因为用户是人类就妥协让步。
- **输出语言默认值**：完全切换为符合中国内地的规范 **简体中文**（摘要可按需生成双语）。
- **学术透明**：对于超出 AI 离线资料库的前沿文献检索，强烈建议由用户提供真实摘要作为上下文喂给 AI，确凿核心引用不被捏造。
