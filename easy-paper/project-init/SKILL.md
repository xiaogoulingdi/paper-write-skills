# Project Init (课题初始化模块)

## 描述
这是一个专用于创建和配置全局工作区“大脑”—— `USER_RESEARCH_PROFILE.md` (课题全局配置文件) 的辅助模块。
当用户获取到本工具箱（Easy Paper Toolkit），准备开始撰写一篇新论文或毕业设计时，通过调用此模块可一键生成专属的专业设定边界。

该设定相当于一个“系统级外挂”，一旦生成，后续不论调用哪个写作或评审 Agent，都会基于这个配置的专业领域来发散，极大降低幻觉和偏题率。

## 包含的智能体 (agents/)
- `profile_builder_agent.md`: 档案构建向导。负责以结构化的方式与用户对话（或直接接收用户丢来的选题），自动从 `templates` 提取骨架，并在根目录生成属于用户的配置文件。

## 包含的模板 (templates/)
- `USER_RESEARCH_PROFILE_TEMPLATE.md`: 全局课题设定的空白模板。规定了必备的字段，如“课题题目”、“体裁限制”、“核心方法论”与“高频硬核词汇”。

## 工作流 / 使用说明 (Workflow)
1. 你只需对 Claude Code 下达指令：“初始化我的课题” 或 “我要开始写论文了”。
2. Claude 将自动加载 `profile_builder_agent`。
3. 智能体将向你询问关键信息（如果你在第一句话里已经说了，比如“我要初始化一个关于图对比学习的安全毕设配置”，它则会自动免打扰分析）。
4. 最终在工作区根目录生成 `USER_RESEARCH_PROFILE.md`。
